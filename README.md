# Moonshot Families
WordPress development for Emory University's Moonshot Families program.

**Live site:** [moonshotfamilies.org](https://www.moonshotfamilies.org/)
**Role:** WordPress Web Developer — HTML, CSS, JavaScript, Python

## What it is
Moonshot Families runs multiple program-facing websites for Emory University. Each site needed to be responsive, fast, and accessible for a broad, non-technical audience.

## What I built
- Engineered and customized responsive WordPress themes (HTML, CSS, JavaScript) across 3+ program websites
- Improved page load times by 25% and raised accessibility standards across the sites
- Built Python converters for HyperAudio transcript scripts, automating formatting that used to be done by hand — cutting transcription formatting time by 40% per script
